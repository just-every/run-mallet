# Mallet first-release contract

These clauses describe intended first-release behaviour. Check results and release evidence must establish which journeys have passed.

- **HTTP-001 — Private app boundary.** Hono serves health/API ownership; native owner/operator sessions protect workshop pages and commands. Direct requests enforce authority, exact host and same-origin mutation checks. Unknown paths return real 404s. Bearer keys have the preparation scope below.
- **WORKSHOP-001 — Register and visits.** Assets have unique case-insensitive identifiers and retain visits. Booking snapshots customer/asset details and refuses overlaps for either the bay or technician. Booking times are ISO timestamps including timezone, normalised to UTC. Member assignment uses the operator ID.
- **ESTIMATE-001 — Exact decision.** Estimates keep revisions, prices and preparer identity. A person approves the current exact revision before recording a manual handoff. Staff record customer identity, selected lines, method and evidence against that revision. Sharing is a record, not email delivery. Partial authorisation freezes the estimate; additional work requires a new visit.
- **WORK-001 — Authorised actuals.** Work uses only lines and quantities within the approved and customer-authorised revision. A member records work only for their assigned jobs. A job needs recorded work before completion.
- **INVOICE-001 — One saved export.** An invoice freezes authorised prices and actual quantities after completion. A person approves it before export. Repeated export returns the saved export rather than creating another invoice or export. The CSV is a generic Mallet AUD file, not automatic posting or a promised Xero import. Unit prices and subtotals exclude GST; taxable lines calculate 10% Australian GST separately with integer-cent rounding.
- **AGENT-001 — Prepare, then person decides.** An expiring, revocable bearer key can read state and invoke only `estimate.prepare`, `estimate.revise`, `dispatch.prepare` and `invoice.prepare`. Agents cannot approve, share, authorise, export or manage data/access. Preparation and human decisions retain actor, timestamp and revision/version evidence. Authority is rechecked at write time.
- **IMPORT-001 — Reviewed register move.** Saved RepairShopr customer and asset snapshots use the Base import kit. Preview writes nothing. Apply requires its exact reviewed fingerprint, retains source originals, links and progress in a journal and supports bounded continuation. Undo refuses records changed or used since import. Previous repair history stays in the source system.
- **DATA-001 — Custody and erasure.** Native Base portability covers workshop records, decisions, saved exports and import custody. Restore requires an empty destination with fresh owner/configuration; identity and credentials are excluded. Only an owner may erase an unused asset with explicit `ERASE` confirmation. Assets with visits are retained. A later erasure journal must accompany an older restored archive.
- **PIER-001 — Read only.** The optional Pier catalogue adapter performs a GET with private authorised connection settings. Stock movements, reservations, allocations and supplier ordering remain outside Mallet.

No local criterion establishes hosted health, invitation delivery, accounting ingestion or external stock changes. Release one excludes payments, registry/OEM/warranty services and supplier networks.
