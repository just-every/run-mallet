Historical baselines do not establish its current verification or landing. REPORT-002 and AUTO-002 are updated by the named i925 journeys in this revision; the historical baseline was judged against code and tests at `88562eb529abd66394171d97778854c4a94fa4b2`. Each paragraph retains the existing journey form and adds its clause ID and current status. `done` means the cited implementation and exercising tests support that clause; it is not production-provider or hosted acceptance. Partial or missing journeys are build work and must pass through public doors with realistic shop data. Only paid or network edges may be faked in tests.

Run the complete US repair: vehicle identification and inspection → priced estimate and line/supplement consent → approved supplier order and receiving → assigned technician work/quality → USD invoice and settled payment → documented return → mileage/declined-work follow-up and reconciled reports. Import source history through the named move-in door; never substitute seeded application records.
